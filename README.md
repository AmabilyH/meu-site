# Mesmo Ano

Site simples onde a pessoa cadastra o nome e a data de nascimento e vê quem mais nasceu no mesmo ano.

## Como usar
1. Abra o arquivo `index.html` no navegador.
2. Digite seu nome e sua data de nascimento.
3. Clique em "Cadastrar" para ver as pessoas nascidas no mesmo ano.

## Observação
Os cadastros ficam salvos apenas no navegador de quem usa.

## Tecnologias
HTML, CSS e JavaScript.
